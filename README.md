Десять отдельных сайтов свадебных и вечерних салонов и мужского шоурума, созданных по предоставленным заказчиком материалам. Разные композиции и цветовые палитры, адаптация под телефон, удобные контакты, FAQ и подготовка обращения на примерку. У ТАТА — конструктор пожеланий; у OPERA — фильтр поводов.

Цены — ориентиры из предоставленных данных; наличие и условия подтверждает салон. Формы только составляют текст для копирования, не отправляют данные и не подтверждают запись.
